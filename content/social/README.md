# Code PR social post queue

This folder is the review queue for Code Puerto Rico's organic social posts (Instagram @code_puertorico first, then Facebook and TikTok). It is not part of the website build.

## How a post moves

1. **draft**: Code PR Media writes the post here as a `.md` file.
2. **review**: Adam (and any experts he asks) comments or edits.
3. **approved**: Adam says OK for that exact post. Only then does anything get scheduled.
4. **scheduled / posted**: the posting rail (n8n, owned by Code PR Automations) or Adam posts it, and the file gets the live link.

Nothing is posted or scheduled without Adam's explicit OK.

## Rules

- Zero paid budget. Organic only.
- Adam's voice: direct, builder-first, English primary with Spanish versions.
- No Holberton case studies and no mention of Holberton's CRM move until Adam says so. Generic CRM-migration content is fine.
- Code PR can be called a Caribbean AI Summit 2026 sponsor, without a tier.
- No secrets, tokens, or private lead data in this folder.
